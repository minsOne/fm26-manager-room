# Vision

FM26 Manager Room should feel like a real manager's backroom staff: it watches the save, finds what needs attention, explains why, and helps the manager decide quickly.

## Core interaction

1. **Manager Room** shows only what needs attention now.
2. **Rooms** provide deeper evidence and alternatives.
3. **AI Coach** answers context-aware questions from the current screen.
4. **Coach Confidence** exposes how certain each recommendation is.
5. **Safe Writer** only automates explicitly approved, whitelisted actions.

## Non-goals

- Editing player CA/PA
- Boosting player attributes
- Editing match results
- Turning the project into a generic cheat editor
